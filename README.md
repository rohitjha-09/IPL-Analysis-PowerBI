# 📊 IPL Ball-by-Ball Performance Analysis (2008–2024)

### 📌 Project Overview
An interactive Power BI dashboard built using IPL ball-by-ball data to analyze batting, bowling, and match dynamics across seasons (2008–2024).

---

### 📊 Dashboard Preview
![IPL Ball-by-Ball Dashboard](images/ipl_ball_by_ball_dashboard.png)

---

### 🔍 Key Insights
- First innings consistently records higher total runs than the second innings, indicating a batting-first advantage  
- Yuzvendra Chahal, Dwayne Bravo, and Piyush Chawla emerge as the most effective wicket-taking bowlers  
- Virat Kohli, Shikhar Dhawan, and Rohit Sharma dominate the run-scoring charts across seasons  
- Wides contribute the highest share of extra runs, highlighting the impact of bowling discipline on match outcomes  
- Interactive slicers enable team-wise, player-wise, and innings-wise dynamic analysis  

---

### 📈 Dashboard Highlights
- KPI cards displaying total runs, balls, wickets, and matches  
- Top 10 batsmen and bowlers analysis using DAX measures  
- Innings-wise run comparison to identify scoring patterns  
- Extras contribution analysis for deeper bowling insights
